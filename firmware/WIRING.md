# 장치별 배선 가이드 (Arduino Uno)

`PINS.md`가 "어떤 핀을 왜 쓰는지"를 다룬다면, 이 문서는 실제로 각 장치를 보드의
어느 헤더에 연결하는지를 다룹니다. 보드 헤더 라벨은 사진 기준입니다.

- `POWER`: `5V · RES · 3.3V · 5V · GND · GND · VIN`
- `DIGITAL PWM~`: `13 · 12 · 11~ · 10~ · 9~ · 8 · 7 · 6~ · 5~ · 4 · 3~ · 2 · TX→1 · RX←0`
  (`~` 표시가 PWM 가능 핀: 3, 5, 6, 9, 10, 11)
- `ANALOG IN`: `A0 · A1 · A2 · A3 · A4 · A5`

> 안전 주의: Uno 디지털 핀은 최대 약 20mA만 안전하게 흘릴 수 있습니다. 모터
> (팬, 커튼)와 고전력 LED는 핀에서 직접 구동하지 말고 반드시 릴레이 모듈 /
> 모터 드라이버(L298N 등) / MOSFET을 거쳐 외부 전원으로 구동하세요. 아래
> 배선은 그 전제로 작성했습니다 — 실제 사용하는 드라이버 모듈이 다르면
> 신호선 연결 방식만 그에 맞게 바꾸면 됩니다.

## 1. Pan Servo

| 서보 핀 | Uno 핀 |
| --- | --- |
| Signal (주황/노랑) | `D9` |
| VCC (빨강) | `POWER` 헤더 `5V` |
| GND (갈색/검정) | `POWER` 헤더 `GND` |

## 2. Tilt Servo

| 서보 핀 | Uno 핀 |
| --- | --- |
| Signal | `D10` |
| VCC | `POWER` 헤더 `5V` |
| GND | `POWER` 헤더 `GND` |

두 서보를 동시에 움직일 때 전류가 부족하면 서보 떨림이 생길 수 있습니다.
그런 증상이 보이면 서보 VCC를 Uno 5V 대신 외부 5V로 옮기고 GND만 Uno와
공유하세요.

## 3. Fan (모터 드라이버 경유)

| 신호 | Uno 핀 |
| --- | --- |
| 드라이버 PWM/속도 입력 | `D5` |
| 드라이버 GND | `POWER` 헤더 `GND` (Uno와 공통 GND 필수) |
| 팬 모터 전원 | 드라이버의 외부 전원 입력 (Uno `VIN`/`5V`가 아님) |

## 4. Light (LED, PWM 밝기 조절)

| 신호 | Uno 핀 |
| --- | --- |
| LED 드라이버/MOSFET 게이트 | `D6` |
| GND | `POWER` 헤더 `GND` |

저전력 LED 한두 개면 저항을 거쳐 `D6`에 직결해도 되지만, LED 스트립처럼
전류가 크면 반드시 MOSFET/드라이버를 경유하세요.

## 5. Curtain Motor (방향 제어, 릴레이 또는 H-브릿지)

| 신호 | Uno 핀 |
| --- | --- |
| 열기 방향 (IN1) | `D7` |
| 닫기 방향 (IN2) | `D8` |
| 드라이버 GND | `POWER` 헤더 `GND` |
| 모터 전원 | 드라이버의 외부 전원 입력 |

`D7`/`D8`을 동시에 HIGH로 두지 않습니다 (`eyecan_room.ino`의
`stopCurtain()`/`openCurtain()`/`closeCurtain()`이 이미 이렇게 배타적으로
제어합니다).

## 6. USB Serial (명령 수신 / ACK 응답)

`TX→1`, `RX←0`은 USB-Serial 통신 전용입니다. 다른 장치를 여기에 연결하지
마세요 — 명령 수신과 `ACK:` 응답이 모두 이 두 핀을 통해 USB 케이블로 오갑니다.

## 아직 배선하지 않은 핀

`D2`, `D3`, `D4`, `D11`, `D12`, `D13`, `A0`–`A5`는 비어 있습니다. Window
모터처럼 향후 하드웨어가 정해지면 `PINS.md`와 이 문서에 함께 추가합니다.
